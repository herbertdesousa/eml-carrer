# Insights

Anotações datadas conforme vou estudando. Um arquivo por sessão de estudo ou por tema, como preferir — vamos ajustar o formato conforme a necessidade aparecer.

Convenção inicial (simples, pode mudar):

- Nome do arquivo: `AAAA-MM-DD-tema-curto.md`
- Conteúdo livre, mas útil marcar:
  - **De onde veio:** material/artigo/conversa que gerou o insight.
  - **O que aprendi:** o insight em si.
  - **Relação com a ementa:** qual tópico de [ementa.md](../ementa.md) isso reforça.
  - **Desmistificar para o time?** se esse ponto vale uma conversa/apresentação com o time de EML, marcar aqui.
