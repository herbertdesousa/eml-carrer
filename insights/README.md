# Insights

Anotações datadas conforme vou estudando. Um arquivo por sessão de estudo ou por tema, como preferir — vamos ajustar o formato conforme a necessidade aparecer.

## Como escrevemos os insights

**O conteúdo é escrito por mim (o autor deste repo), não pelo Claude.** Escrever é parte de como fixo o conhecimento. O papel do Claude é criar o arquivo com o esqueleto pronto (título, seções, contexto de onde veio a dúvida) e depois, se eu pedir, revisar/complementar o que eu já escrevi — nunca preencher a nota do zero no meu lugar.

Fluxo:
1. Durante a conversa, quando algo virar insight, eu peço para o Claude criar o arquivo com a seção pronta (vazia).
2. Eu escrevo o conteúdo com minhas palavras.
3. Se quiser, peço para o Claude revisar, complementar ou apontar lacunas depois que eu já escrevi.

Ver [_template.md](_template.md) para o esqueleto padrão.

Convenção (simples, pode mudar):

- Nome do arquivo: `AAAA-MM-DD-tema-curto.md`
- Seções do template:
  - **De onde veio:** material/artigo/conversa que gerou o insight.
  - **O que aprendi:** o insight em si (a escrever).
  - **Relação com a ementa:** qual tópico de [ementa.md](../ementa.md) isso reforça.
  - **Desmistificar para o time?** se esse ponto vale uma conversa/apresentação com o time de EML, marcar aqui.
